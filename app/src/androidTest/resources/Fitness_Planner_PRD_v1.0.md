# Fitness Planner Android APP 需求规格说明书（PRD v1.0）

## 一、项目概述

开发一款 Android 原生健身训练计划助手，支持：

-   今日训练查看
-   训练计划管理
-   JSON 导入导出
-   本地离线存储

------------------------------------------------------------------------

## 二、技术要求

  项目       要求
  ---------- ---------------------
  开发语言   Kotlin
  UI框架     Jetpack Compose
  架构       MVVM
  数据库     Room Database
  导航       Navigation Compose
  最低SDK    Android 8.0(API 26)
  数据存储   本地存储
  网络依赖   无

------------------------------------------------------------------------

## 三、页面结构

底部导航包含三个页签：

1.  首页（今日训练）
2.  训练计划
3.  设置

------------------------------------------------------------------------

## 四、首页（今日训练）

### 功能

-   显示当天训练任务
-   无任务时显示"今日休息"
-   支持勾选完成训练项
-   显示训练完成率

### 显示内容

-   当前日期
-   星期信息
-   今日训练项目列表
-   完成率统计

------------------------------------------------------------------------

## 五、训练计划页

### 功能

-   查看全部训练计划
-   新增训练计划
-   编辑训练计划
-   删除训练计划

### 计划结构

> 计划1 - 开始时间
> > 动作1 组数 次数 间歇
> 
> > 动作2 组数 次数 间歇
> 
- 每一项都要支持修改，删除
------------------------------------------------------------------------

## 六、训练项目

每个训练项目包含：

-   项目名称
-   次数（可为空）
-   时长（可为空）
-   间歇时间（可为空）

------------------------------------------------------------------------

## 七、训练逻辑

计算公式：

``` text
days = 今天 - startDate

days % interval == 0
```

满足条件则显示训练任务，否则显示今日休息。

------------------------------------------------------------------------

## 八、设置页

### 导出功能

导出所有训练计划为 JSON 文件。

### 导入功能

导入符合规范的 JSON 文件。

------------------------------------------------------------------------

## 九、JSON格式

``` json
{
  "plans": [
    {
      "id": 1,
      "name": "胸部训练",
      "startDate": "2026-06-01",
      "interval": 1,
      "items": [
        {
          "name": "俯卧撑",
          "count": 20,
          "duration": null,
          "rest": 30
        }
      ]
    }
  ]
}
```
